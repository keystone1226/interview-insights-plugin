## 참여 방법

1. 이 레포를 fork 또는 clone 합니다.
2. 자신의 브랜치를 생성합니다: `study/<github-username>/week<N>`
3. 해당 주차 폴더에 과제를 작성합니다.
4. PR을 열어 리뷰를 요청합니다.

## 폴더 구조

```
study/
├── week01/
│   ├── README.md          # 주차 안내 (주제, 참고자료)
│   └── <username>/        # 각자 과제 제출 폴더
│       ├── notes.md       # 학습 정리
│       └── demo/          # 데모 코드 (선택)
├── week02/
│   └── ...
└── ...
```

## 과제 제출 가이드

1. `study/weekNN/` 아래 자신의 GitHub username 폴더를 만듭니다.
2. `notes.md`에 학습 내용을 정리합니다.
3. 코드 데모가 있으면 `demo/` 폴더에 넣습니다.
4. PR 제목 형식: `[Week N] <username> - <주제 요약>`
