```

```

### 2️⃣ 모임 당일 — 스탠드업

> 스터디 시작 시간에 봇이 스탠드업을 진행합니다.

```
🧍 [Week 3] 스탠드업을 시작합니다!

아래 질문에 스레드로 답변해주세요:

1. 이번 주 학습한 내용은?
2. 어려웠거나 흥미로웠던 점은?
3. 다음 주 계획은?

💡 답변은 간단하게, 2-3줄이면 충분합니다.
```

각자 스레드에 답변을 남기면 됩니다.

### 3️⃣ 모임 후 — 자동 정리

> 봇이 스탠드업 내용과 논의 사항을 자동 수집하여 정리합니다.

- 스탠드업 답변을 요약하여 GitHub 레포에 저장
- `study/week03/standup-summary.md` 형태로 아카이빙
- 누가 어떤 내용을 학습했는지 한눈에 볼 수 있음

## 과제 제출 방법

매주 학습한 내용을 GitHub에 기록합니다.

### Step 1. 브랜치 생성
```bash
git checkout -b study/<github-id>/week03
```

### Step 2. 학습 내용 작성
```bash
mkdir -p study/week03/<github-id>
cp study/TEMPLATE_notes.md study/week03/<github-id>/notes.md
# notes.md를 편집하여 학습 내용 정리
```

### Step 3. PR 생성
```bash
git add .
git commit -m "study(week03): <github-id> - <주제 요약>"
git push -u origin study/<github-id>/week03
```
GitHub에서 PR을 올리면 봇이 자동으로 리뷰를 도와줍니다.
